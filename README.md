# Stopwatch Web Application
A lightweight and responsive stopwatch built with HTML, CSS, and JavaScript.
It allows users to start, stop, reset, and record lap times with a clean and modern interface.

# Features
1. Start/Stop functionality
2. Reset to zero
3. Lap recording with automatic numbering

# How to Run
1. Clone the repository:
   ```bash
   https://github.com/Hlompho-Khoali/stopwatch-app.git
2. download the project files.
3. Make sure you have the following files in the same folder:
- index.html (your main HTML file)
- style.css (styling)
- script.js (stopwatch logic)

4. Open index.html in any modern web browser (Chrome, Edge, Firefox, etc.).
5. Use the buttons to control the stopwatch and record laps.
